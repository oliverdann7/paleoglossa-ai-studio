# Release notes — 1.0.0

## What's New (App Store / Play Store)

Initial release of Paleoglossa.

- Read 11 ancient languages with word-level morphology and lemma lookup.
- FSRS-5 spaced repetition for every word you mark.
- AI philology tutor with six difficulty modes.
- Treebank syntax viewer (PROIEL / Gorman / Perseus).
- Pronunciation lab with restored, Erasmian, and modern traditions.
- IIIF manuscript viewer.
- Research notebooks with cross-text backlinks.
- Firebase-backed multi-device sync.
