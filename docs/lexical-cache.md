# Lexical Cache

The Lexical Cache is a server-side storage mechanism designed to reduce AI costs and latency by caching results of word gloss generation and explanations.

## Lookup Order

1.  **User Gloss**: Definitions saved by the user.
2.  **Curated Dictionary**: Stored in the application bundle.
3.  **Token Gloss**: Glosses embedded directly in the text corpus.
4.  **Wiktionary**: Community-contributed dictionary lookups.
5.  **Server-Side Lexical Cache**: Persistent cache for AI-generated glosses.
6.  **AI Generation**: Live AI lookup as a last resort.
7.  **LocalStorage**: Client-side fallback for offline access.

## Privacy

The cache stores lemmas and AI-generated glosses. No personally identifiable information (PII) is included in the cache entries.

## Source Trust

Cache entries generated by AI and stored in the server-side cache are labeled as "AI cached" in the UI to indicate they are not curated reference dictionary entries.

## Local Development Fallback

In environments where Firebase Admin SDK is not configured, the server-side lexical cache falls back to an in-memory `Map` within the API process. This ensures that the application remains functional during development and testing without requiring live Firestore access.
